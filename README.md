# 🎓 UB Campus Event Finder

A desktop application built with Java and JavaFX that helps University of Botswana students find and manage campus events.

## Features

- Add campus events with title, description, location, category and date
- View all events in a clean organized table
- Search events by title, category or location
- Filter events by category (Academic, Sports, Social, Career)
- Delete events
- Data saves automatically and persists after closing

## Technologies Used

- Java 24
- JavaFX 21
- Maven
- File I/O

## How to Run

### Prerequisites
- Java JDK 8 or higher
- Maven

### Steps
1. Clone the repository
    git clone https://github.com/kobedimotheo2/campus-event-finder.git
2. navigate to project folder 
3. Run the app
   mvn javafx:run
